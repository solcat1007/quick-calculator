# 极简计算器 (Quick Calculator)

简洁美观的网页计算器，支持鼠标点击和键盘输入。

## 功能

- **四则运算**：加减乘除基本运算，支持连续计算
- **百分比**：一键转换为百分数
- **正负号切换**：点击 +/- 切换数值正负
- **小数点**：支持小数运算
- **实时显示**：表达式和结果显示分离，计算过程清晰可见
- **键盘支持**：支持数字键和运算符键盘输入，Enter 计算结果，Esc 清空
- **中英文切换**：界面支持中文/英文
- **自动全屏**：打开后自动进入全屏

## 使用方法

1. 用浏览器打开 `index.html`
2. 点击数字和运算符按钮进行计算
3. 或直接使用键盘输入（数字键 + 运算符 + Enter 计算 + Esc 清空）
4. 点击 C 清空所有内容

## 技术栈

纯 HTML/CSS/JavaScript。
