# 极简计算器 (Quick Calculator) v2.0

简洁美观的单文件 PWA 计算器，支持鼠标与键盘双输入。

## 🆕 v2.0 更新

- 新增 **幂运算**（`^` 按钮与键盘 `^`，如 `2^10`）
- 新增 **计算历史**（localStorage 保存最近 30 条，点击还原表达式）
- **键盘完整支持**：数字、四则运算、括号、百分比、幂运算、退格、清空全覆盖
- 新增 **一键复制结果** 与 ± 正负号切换
- 注入 SOLCAT 彩蛋引擎，UI 全面美化

## 功能

- **四则运算**：加减乘除，支持括号与连续计算
- **百分比 / 幂运算**：`50%` 自动按 0.5 处理，`^` 计算幂次
- **键盘操作**：`Enter`/`=` 计算，`Esc`/`C` 清空，`Backspace` 退格，`^` 幂运算
- **历史记录**：本地持久化，点击历史行回填表达式
- **复制结果**：点击复制按钮即可复制当前结果
- **中英文切换**：界面文案同步切换

## 使用方法

1. 打开 `index.html`
2. 点击按钮或直接敲键盘输入表达式
3. 按 `Enter` 或点 `=` 得到结果，结果自动进入历史
4. 点击「复制」把结果放入剪贴板

> 安全说明：不使用 `eval()`。先做字符白名单校验，再将 `× ÷ ^ %` 转成合法 JS 运算符后求值。

## 🥚 彩蛋秘籍

| 操作 | 效果 |
|------|------|
| ↑ ↑ ↓ ↓ ← → ← → B A | 全屏彩带烟花 |
| 连点标题 5 次 | 开发者模式面板 |
| 输入 `solcat` 后回车 | 赛博朋克隐藏主题 |
| Ctrl + Shift + T | 切换赛博朋克主题 |

**本作专属**：解锁任意彩蛋后，计算器会自动算出 `6×7 = 42`。

## 技术栈

纯 HTML / CSS / JavaScript，localStorage + Service Worker。
